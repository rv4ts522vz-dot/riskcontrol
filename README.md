# RiskControl — мониторинг рисков на 2 млн записей

Сайт с тревожной кнопкой, аналитикой по 2 000 000 инцидентов в PostgreSQL и QR-кодом для перехода с телефона.

## Структура
```
├── render.yaml         — Blueprint: Render сам создаёт базу и сайт
├── server.js           — сервер и API
├── db.js               — подключение к БД, схема таблиц, материализованное представление
├── seed-2m.js          — генерация 2 000 000 инцидентов прямо в базе
├── setup-database.js   — ручное создание таблиц (необязательно)
├── package.json
└── public/
    ├── index.html      — панель: тревожная кнопка, аналитика, реестр, QR-код
    ├── qr.html         — страница-плакат с QR-кодом для печати
    ├── qr.js           — генератор QR-кодов без внешних библиотек
    └── style.css
```

## Развёртывание с нуля (GitHub + Render)

### 1. GitHub
Создай новый репозиторий и загрузи в его корень все файлы из этой папки
(Add file → Upload files). Файл `.env` загружать нельзя — в нём пароль.

### 2. Render
1. Если у тебя уже есть бесплатная база на Render, удали её: бесплатная база доступна только одна.
2. **New → Blueprint** → выбери репозиторий → **Apply**.
   Render прочитает `render.yaml` и создаст базу `riskcontrol-db` и сайт `riskcontrol`.
3. Дождись статуса **Live** у сайта. Сайт уже работает, но база пустая (везде 0).

### 3. Заполни базу (со своего компьютера, один раз)
1. На Render открой `riskcontrol-db` → **Connect** → скопируй **External Database URL**.
2. Установи Node.js (nodejs.org). Скачай репозиторий (Code → Download ZIP) и распакуй.
3. В папке создай файл `.env`:
   ```
   DATABASE_URL=вставь_External_Database_URL
   ```
4. В терминале в этой папке:
   ```
   npm install
   npm run seed
   ```
   Таблицы создадутся сами. Генерация на бесплатной базе Render идёт ~5–15 минут.
   Дождись строки «Всё готово». Если будет ошибка про нехватку места —
   `node seed-2m.js --reset --count=1500000`.
5. Открой сайт и нажми «↻ Обновить» — должно стать 2 000 000.

### 4. QR-код
- На панели кнопка **▣ QR-код** показывает код, ведущий на сайт.
- Страница `https://твой-сайт.onrender.com/qr.html` — плакат с QR-кодом для печати или для слайда презентации.
- Адрес в QR-коде берётся из адреса открытой страницы, поэтому настраивать ничего не нужно.

## Ограничения бесплатного Render
- База: 1 ГБ, **удаляется через 30 дней** после создания (+14 дней на апгрейд). Создавай её не раньше чем за пару недель до защиты.
- Сайт засыпает после 15 минут без посещений, первое открытие ~1 минута. Открой сайт заранее перед показом.

## Как устроена работа с большими данными
- **Материализованное представление `mv_incident_cube`** — 2 млн строк заранее свёрнуты в ~8 700 строк
  (месяц × категория × приоритет × статус × уровень риска). Карточки и графики считаются по нему за миллисекунды.
- **`REFRESH MATERIALIZED VIEW CONCURRENTLY`** — пересчёт (~3 с) в фоне через 3 с после нового сигнала и раз в 10 минут.
- **Keyset-пагинация** (`WHERE incident_id < курсор`) — любая из 100 000 страниц реестра открывается одинаково быстро.
- **Индекс `risk_assessments (incident_id, assessed_at DESC)`** — мгновенный поиск последней оценки риска.

## API
| Метод | Адрес | Что делает |
|---|---|---|
| GET | /api/health | проверка подключения к БД |
| GET | /api/dashboard | показатели и графики |
| GET | /api/incidents?type=&priority=&status=&before= | реестр с фильтрами, по 20 записей |
| POST | /api/incidents | новый сигнал `{incident_type, amount, description, panic}` |
| POST | /api/analytics/refresh | принудительно пересчитать аналитику |
